# WhisperScribe

WhisperScribe is a modern, lightweight desktop application designed for fast, accurate local audio transcription and subtitle generation. Built with Python, PyQt6, and powered by OpenAI's Whisper model (via faster-whisper), it offers real-time audio chunk processing, GPU acceleration support, and export options in multiple formats.

*Key Features*

Local & Private Processing: Transcribe audio files locally on your machine without relying on external cloud APIs or uploading sensitive data.

Real-Time Segment Processing: Transcribes audio segments continuously with real-time feedback.

Multiple Model Sizes: Choose between different Whisper model sizes (tiny, base, small, medium, large-v3) to balance speed and accuracy.

Modern Desktop UI: Built using PyQt6 with full support for dark mode and clean visual indicators.
